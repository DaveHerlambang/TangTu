# TangTu — Tanggal Tua

*Selamat datang di tanggal tua.* An offline, private money tracker: log where your money goes in
categories you define, and see the month at a glance. English | Bahasa Indonesia.

- Product spec: [`docs/SPEC.md`](docs/SPEC.md) — read it before changing behaviour.
- Rules for contributors and AI agents: [`AGENTS.md`](AGENTS.md)
- Release history: [`CHANGELOG.md`](CHANGELOG.md)

```bash
npm install
npx expo start          # dev client; add --go for Expo Go
npm run typecheck && npm test && npx expo lint
```
